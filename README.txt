# Proposal website inspired by the uploaded reel

This version recreates the feel of the reel:
- Pink/lilac gradient background
- Floating hearts/petals
- "A SMALL QUESTION" heading
- Large romantic question
- Gradient YES button
- Shy/moving NO button
- YES opens an "IT'S OFFICIAL" celebration screen
- Mobile-first design

Open `index.html` to run it.

## Private response
The demo stores the YES response in localStorage on her device. That is NOT enough to let you see her response remotely.

For a real private link where you can see her answer from your phone, connect the YES/NO actions to a private Supabase table and an admin page. The existing front end is ready to be connected to that backend.
